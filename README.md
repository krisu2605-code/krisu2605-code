## Kristel Talaver

Self-taught developer based in Hanoi, Vietnam. I build production software and debug it when it breaks — my background is ~5 years in technical support, now moving into solutions and support engineering.

**VaultContext** — a live, read-only Google Calendar conflict-detection service I built and operate end-to-end.
- Node.js/Express on Render, Supabase (Postgres + auth), FlutterFlow frontend, Google Calendar API + OAuth 2.0, Resend for email, ElevenLabs for voice alerts.
- Detection is deterministic timestamp math, not an LLM — chosen on purpose for correctness.
